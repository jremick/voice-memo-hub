# Roadmap

## Alpha

- Stabilize the external policy schema.
- Add migration handling for SQLite schema changes.
- Add packaged install instructions.
- Expand read-only MCP tools for dashboards and third-party clients.
- Add safer notification configuration docs.
- Improve action extraction beyond the current heuristic classifier.

## Beta

- Provide a clean service installer for the always-on Mac.
- Document compatibility across macOS and Python versions.
- Add import/export snapshots for secondary machines.
- Add a stronger approval and audit trail for workflow execution.
- Publish examples for common knowledge and task-capture flows.
